# PyError Analyzer

## About the Project
PyError Analyzer is a simple Python mini project designed to help beginners understand common Python errors with their reasons and suggestions.

## Features
- Simple menu-driven interface
- Accepts Python code from the user
- Displays the selected error type
- Explains the reason for the error
- Provides suggestions to fix common errors

## Errors Covered
1. SyntaxError
2. NameError
3. TypeError
4. IndexError
5. ZeroDivisionError

## Technologies Used
- Python
- Loops
- Conditional Statements
- User Input and Output

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file.

## Purpose
This project was created to practise Python programming and help beginners learn about common coding errors.
